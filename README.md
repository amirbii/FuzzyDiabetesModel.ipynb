# Fuzzy Diabetes Risk Prediction System

این پروژه یک سیستم فازی با استفاده از کتابخانه‌های Python مانند `scikit-fuzzy` طراحی می‌کند تا خطر ابتلا به دیابت را بر اساس سه ورودی اصلی ارزیابی کند:

- سن (AGE)
- شاخص توده بدنی (BMI)
- فشار خون (BP)

## ویژگی‌ها
- تعریف مجموعه‌های فازی برای هر ویژگی ورودی و خروجی
- استفاده از ۱۶ قانون فازی برای استنتاج سطح ریسک
- پیش‌بینی مقدار ریسک (Y) به صورت عددی
- نمایش گرافیکی نتیجه پیش‌بینی‌شده

## پیش‌نیازها
```bash
pip install numpy pandas scikit-fuzzy scikit-learn openpyxl
```

## فایل داده
فایل `diabetes.xlsx` باید شامل داده‌های مربوط به بیماران (مانند سن، BMI، فشار خون، و دیگر ویژگی‌ها) باشد. این فایل با استفاده از `pandas` بارگذاری می‌شود.

## اجرای سیستم
در این مثال، مقادیر ورودی به صورت دستی مقداردهی شده‌اند:
```python
diabetes_pred.input['AGE'] = 30
diabetes_pred.input['BMI'] = 28
diabetes_pred.input['BP'] = 115
```

و نتیجه:
```python
print(f"Predicted Y: {diabetes_pred.output['Y']:.2f}")
```

نمایش گرافیکی نتیجه نیز با تابع `view` انجام می‌شود:
```python
y.view(sim=diabetes_pred)
```

## هدف
مدل طراحی‌شده می‌تواند به عنوان یک ابزار کمکی در پیش‌بینی میزان ریسک ابتلا به دیابت در بیماران استفاده شود. در ادامه می‌توان آن را گسترش داد تا داده‌های واقعی بیشتری را تحلیل کرده یا به‌صورت تعاملی مورد استفاده قرار گیرد.
